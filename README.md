# 📱 REGE Official

> Platform Digital Karang Taruna Indonesia

REGE Official adalah aplikasi berbasis JavaScript yang dirancang untuk membantu kegiatan organisasi Karang Taruna menjadi lebih modern, transparan, dan mudah diakses oleh seluruh anggota.

---

# ✨ Fitur

## 👤 Akun

- Login
- Registrasi Anggota
- Edit Profil
- Upload Foto Profil

---

## 📰 Beranda

- Feed Postingan
- Story Anggota
- Like
- Komentar
- Edit Caption
- Hapus Postingan
- Preview Gambar

---

## 📌 Pengumuman

- Dynamic Announcement
- Auto Hide jika tidak ada pengumuman
- Persiapan Sticky Announcement

---

## 👥 Organisasi

- Data Anggota
- Role Admin
- Role Member
- Sinkronisasi Profil

---

# 🚀 Teknologi

- HTML5
- CSS3
- JavaScript ES6
- LocalStorage
- CropperJS
- Cloudinary
